# Sell Christmas Trees vault

Obsidian notes for the Roblox game Sell Christmas Trees (Studio place: Build a Christmas Tree Empire, placeId 87163912011225). Start at [[Home]].

## Sync (GitHub instead of Obsidian Sync)

This folder is a git clone of https://github.com/oscarbech/Sell-Christmas-Trees and is used on several devices.

- Before starting any work here: `git pull --rebase` (stash local changes first if there are any).
- After finishing each change: commit and `git push`.
- Don't use Obsidian Sync or any other upload; GitHub is the only sync.
- `.obsidian/workspace*.json` is per-device and ignored.
