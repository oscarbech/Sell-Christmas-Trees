# Commands

Only work in Studio, or for the group owner in the live game.

| Command | Does |
|---|---|
| `/inf` | +10,000,000 cash on the plot you're on |
| `/wipe` | resets your own save to a brand-new player and saves it (settings stay; no confirmation) |
