# Events

Random plot events, 60 s each. The first one comes 90–150 s after joining, then one every 180–300 s. The plot gets `EventName` / `EventEnds` attributes and `EventBanner` shows a countdown.

| Event | Effect |
|---|---|
| Holiday Rush | every tree sells for 2× |
| Golden Hour | golden trees keep popping up |
| Lumber Frenzy | double logs from every tree |
| Car Parade | cars arrive 3× faster (needs [[Drive-Thru]]) |

Source: `TreeFarmConfig.Events`.
