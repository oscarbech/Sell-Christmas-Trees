# Settings

Toggles are player attributes `Setting_<Name>` (on by default), saved with the player's plot ([[Saving]]).

| Setting | Controls |
|---|---|
| Sound | game sound effects |
| Shake | camera kick |
| Guide | tutorial arrow beam |
| Events | event banner ([[Events]]) |
