# Workshop & Decorating

> **Removed (2026-11-16):** the Workshop building (decorator, DECORATE / COLLECT pads, and the only **RebirthPad**) was deleted from `PlotExpansions`. Its ground is now the [[Drive-Thru]]. The code for it is still there and does nothing without the piece. Decorated trees can still come from elsewhere (e.g. [[Tree Lot]] stock).

- BUILD WORKSHOP (5,000, needs the drive-thru open) adds a decorating workshop east of the shop.
- The decorator turns plain trees into **decorated trees**: 3 s each (faster with FASTER MAKER, min 1 s).
- Decorated trees sell for **2.5×** everywhere, and more at the [[Tree Lot]].
